# FizzyChat

Local and global Paper chat, with staff spy and DiscordSRV integration.

Requires Java 21 and Paper 1.21.11. Build and run checks with gradlew.bat build on Windows or sh gradlew build on Linux. The output JAR is under build/libs.

Place an official DiscordSRV 1.30.5 JAR at libs/DiscordSRV-1.30.5.jar before building. Install DiscordSRV separately for Discord integration. Verify local chat privacy with your server and any log forwarding.
